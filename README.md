# GO-DONE

## Description

It's a CLI tool written in Go that enables users to manage a list of todos.

### Functionalities

-   Create a task
-   Complete a task
-   Delete a task
-   List all tasks

### Commands

#### LIST

```bash
go run main.go list
```

#### CREATE

```bash
go run main.go create <"name of the task">
```

#### COMPLETE

```bash
go run main.go complete <id_of_the_task>
```

#### DELETE

```bash
go run main.go delete <id_of_the_task>
```

## Installation

### Prerequisites

You must install Go language _1.23_.
